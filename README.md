# Treino de Git e GitHub 🚀

Este é um repositório focado no aprendizado prático de controle de versão utilizando Git e GitHub, desenvolvido durante as aulas da Alura.

## 🛠️ Desafios Concluídos

Durante os testes práticos, consegui dominar os seguintes comandos:

- **Visualizar Histórico:** `git log --oneline` para navegar pelos commits.
- **Modificar Commits:** Uso do `git commit --amend` para ajustar mensagens.
- **Reverter Alterações:** `git revert` para desfazer mudanças de forma segura.
- **Apagar Histórico:** `git reset --hard` para viajar no tempo e deletar commits locais.
- **Sincronização:** Conexão com repositório remoto e uso do `git push`.
